# DOME-NPM-002: Install script runs an unexpected file

| Category | Default level |
|---|---|
| `autorun` | 🟠 review |

An install script runs a file that is not tracked source or a known build output.

## Why it matters

An honest install hook runs code you can read in the repository (`node scripts/setup.js`) or a build output (`node dist/install.js`). A hook that runs an asset, or a file that only appears after something else downloads it, hides what it does.

## What Dome reports

- An install script runs a file that is not a script (such as a font or image).
- An install script runs a file that is not in the repository and is not a known build output.

Reasons are fixed text. A finding never quotes the scanned repository.

## False positives

Hooks that run a file generated by an earlier step outside the usual build folders. Accept them with a hash-pinned `allow` entry.

Accept a reviewed finding with a hash-pinned entry in `.dome.yml` (`dome scan . --explain` prints one). Editing the file invalidates the exception.
